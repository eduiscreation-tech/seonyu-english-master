PC·갤럭시 태블릿에서 동일한 HTTPS 주소로 공부할 수 있어요.

이 공개 웹앱에는 교재 사진이나 교재 문장이 들어 있지 않습니다. 개인 학습 데이터(1~100강)를 기기에 한 번 불러오면 시작할 수 있어요. 50강 사용자도 설정에서 100강 데이터를 등록하면 진도는 그대로 유지됩니다.

학습 데이터 파일(.json)을 선택해 주세요.
① 채팅에서 받은 개인 학습 데이터 JSON을 태블릿이나 PC에 다운로드하세요.
② 위에서 파일을 선택하면 브라우저에만 저장됩니다.
③ 기존 학습 기록이 있다면 설정 → 백업 복원으로 불러오세요.
공개 GitHub 저장소에는 개인 학습 데이터, 교재 사진, 학습 기록을 넣지 않습니다. 학습 기록과 교재 데이터는 이 브라우저에 저장되므로 기기 간 자동 동기화는 아직 지원하지 않습니다. 중요한 기록은 정기적으로 백업해 주세요.
